# HomeWork
Chrome web store: https://chromewebstore.google.com/detail/homework-ordering-system/kkmkkmjbjejopnggbkjacmabipmolcef
This extension provides a way for students of St Michael's Grammar School to create tasks, order and prioritise their homework tasks. Please follow either of these sets of instructions to use the extension via your preferred method.

## Instructions for downloading via chrome://extensions/:
 - Press the "code" button on the homepage of the GitHub.
 - Press the "download ZIP" button.
<img width="919" height="548.5" alt="image" src="https://github.com/user-attachments/assets/4bb361d6-b463-4ee3-a77a-e0921aed8e00" />


 - Save the ZIP file to your computer

 - Open a chromium-based website (Chrome, Firefox, Microsoft Edge, Brave, Opera GX)

 - Go to chrome://extensions/

 - Turn on developer mode in the top right corner

 - Press the "Load unpacked" button in the top left corner.
<img width="640" height="92" alt="image" src="https://github.com/user-attachments/assets/a4afafa3-22e2-4ca2-958b-38fce2e62bcd" />

 - Choose the zipped file to open.

 - Press the icon for the extension or ctrl+b (cmd+b) to open the extension popup

 - Follow instructions on the popup



## Instructions for downloading via Chrome Web Store:

 - Open a chromium-based website (Chrome, Firefox, Microsoft Edge, Brave, Opera GX) on a non-SMGS account and on non-SMGS WIFI

 - Open the Chrome Web Store link for my extensions (shown at the top of this page) or search for "Homework ordering System" in the Chrome Web Store

 - Press the icon for the extension or ctrl+b (cmd+b) to open the extension popup

 - Follow instructions on the popup
